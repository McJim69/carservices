## ✨ Overview
The **Louie Car Aircon Portal** is a web application designed to provide secure and managed internet access.  
It includes two modules: **Public Site** and **Admin Site**, functioning as a lightweight **Sales & Inventory System** with booking and service management features.

---

## 🛠 Tech Stack
- PHP  
- HTML / CSS  
- Apache  
- jQuery & JavaScript  
- MySQL Database  
- Bootstrap Framework  
- Custom Framework  
- Corona Dark Admin Template  

---

## 👩‍💼 Management Features

### General
- Built with **two modules**: Public and Admin.  
- Supports service listings, bookings, inquiries, and inventory management.  

### Public Site
- **Home Page** – overview of services.  
- **About Us** – company background.  
- **Products & Services** – browse offerings with full details.  
- **Galleries** – photos and media.  
- **Booking Form** – submit service requests with required fields.  
- **Contact Page** – send messages or inquiries.  

### Admin Site
Accessible only to management with valid credentials.  
Two roles: **Administrator** (full access) and **Staff** (limited access).  

Key Features:  
- **[System Settings](ca://s?q=Explain_System_Settings_in_Admin)** – manage About, Services, Categories, Units, Website Info.  
- **[Product & Customer Management](ca://s?q=Explain_Product_Customer_Management)** – add/edit products, customers, technicians, transactions, sales, manufacturers.  
- **[Database Tools](ca://s?q=Explain_Database_Tools_in_Admin)** – view, backup, restore, empty data.  
- **[Media Galleries](ca://s?q=Explain_Media_Galleries_in_Admin)** – manage photos and pictures.  
- **[User Management](ca://s?q=Explain_User_Management_in_Admin)** – add/edit/remove system users.  
- **[File Handling](ca://s?q=Explain_File_Handling_in_Admin)** – upload/download files.  
- **Theme Options** – dark/light mode.  
- **Authentication** – login/logout.
